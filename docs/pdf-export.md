# PDF export

The primary toolbar action prepares a PDF through the browser's native print dialog. Choose **Save as PDF** there. This keeps normal document text selectable and uses the browser's CSS/vector/font rendering, without uploading the CV or adding a rendering-service credential. JSON, portable HTML and original source remain in the adjacent export menu.

The exporter snapshots the current validated document and its selected CV language. Visual documents, saved React templates and HTML source share the same path. React executes only in a temporary opaque iframe with the existing network-denying CSP; the parent accepts a message only from that frame. The received markup is sanitized again, then mounted in a separate inert print document whose CSP disables scripts, frames, external resources, forms and base URLs. Its opener is cleared. Fonts and images finish loading before printing; rendering errors go through the shared copyable error notice. A blocked popup reports an actionable error rather than silently downloading a different format.

Images are optimized in the print copy only, at up to three source pixels per rendered CSS pixel (288 dpi). No image is enlarged. JPEG photographs use quality 0.9; PNG/WebP sources retain alpha via PNG, and a re-encoded copy is retained only when smaller. Cover/contain fitting and scaling are accounted for by the actual rendered image bounds. Existing vector icons stay vectors. Background-image CSS and SVG-embedded raster resources are not recompressed. This changes neither canonical assets nor undo history.

Browser journeys exercise a large synthetic photograph, the React portrait template and an active HTML-source attempt. They generate the actual Chromium PDFs from the same prepared print page after intercepting only the native dialog. Local review uses Poppler page rendering, text extraction and PDF metadata checks. The synthetic photograph's encoded data URL fell from 294,923 to 6,107 ASCII bytes at 300px, with the 1800px original unchanged. This particular fixture is a gradient; it is not a general photographic compression ratio. Both inspected samples are one-page A4 PDFs with no JavaScript and readable text. The Profile render produces a Poppler Type3-glyph bounding-box warning; the opened full-page render shows no missing/clipped glyphs.

Custom visual page dimensions are retained in the print CSS and PDF MediaBox; a 420px square is checked as 315pt. Source snapshots preserve inert body/html styling and language attributes. Closing preparation aborts its sandbox lifecycle without reporting a false error. The separate print window uses the same breathing-orb renderer and a short shimmer label while it prepares, then removes every animation before printing.

The PDF is created by the user's browser dialog, not a background one-click file download. Print destinations, font subsetting, accessibility tags, color management and some filter/blend output depend on the browser. This is not PDF/A or a universal ATS certification. Source PDF output is its rendered snapshot, not a reverse conversion into editable layers. The existing one-page/freeform document contract is unchanged.
