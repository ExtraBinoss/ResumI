## Reproduction and boundaries

Run `bun run check`, then `bun run visual:check`. `BASE_URL` targets an existing server. `RESUMI_PROFILE_LABEL=latest bun run profile:create` writes versioned conditions, timings, resources, screenshot and trace; `RESUMI_PROFILE_SERVER_STATE` describes the actual server condition without hidden warmup. `bun run benchmark:search` regenerates the catalog benchmark. [PDF behavior](pdf-export.md), [languages and extension](localization.md), [architecture](architecture.md) and the [master checklist](../tasks/check-list.md) document the contract.

Tasks 19–25 complete this local revision. CLI projects are explicit files; screenshots require the Playwright Chromium binary and embedded assets. CLI capture runs without a dev server and does not access browser projects. Storage is browser-local; undo history is session-local. Groups remain flat and freeform output uses one explicitly sized page. Source/canvas are preserved representations, without arbitrary two-way conversion. Main interface controls have EN/FR resources; detailed inspector labels remain English, and adding a CV language does not automatically translate content. PDF uses the native print dialog, not a background PDF service. Chromium on Linux is the verified browser here; wider browser/device certification, automatic pagination, inference, MCP/WebMCP, auth/cloud sync and production deployment remain outside this delivery.
